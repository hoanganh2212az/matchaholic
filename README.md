# matcha.holic menu

A standard Next.js app for the matcha.holic menu and order handoff.

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Vercel

Use the default Vercel Next.js settings:

- Framework Preset: `Next.js`
- Build Command: `npm run build`
- Output Directory: leave empty / default
- Install Command: `npm install`

Optional environment variable:

```bash
NEXT_PUBLIC_SITE_URL=https://matchaholic.vercel.app
```

## Scripts

```bash
npm run dev
npm run build
npm run lint
npm test
```
